# NEET Quest 2027 — Stage 1 starter

This is a mobile-first Progressive Web App (PWA) starter. It includes:
- Daily task checklist and custom tasks
- Local progress/XP and chapter checklist
- Board countdown to 16 February 2027
- Mistake notes saved on this device
- Basic service-worker caching for offline access after first load

## Important limitations
- This is **Stage 1 starter**, not the final complete app.
- The chapter list is a rough starter and **not a verified CBSE 2026–27 syllabus**. Check the official CBSE syllabus before using it for syllabus completion.
- It does not yet include a real AI service, actual MCQ question bank, spaced-repetition scheduler, full analytics, or Android device testing.
- Data is stored locally in the browser on this device. Clearing browser/site data can erase it.

## Deploy using GitHub Pages (Android-friendly instructions)
1. Open your repository: https://github.com/ajby26952-bit/neet-quest
2. Tap **Add file → Upload files** (or use GitHub in Chrome with Desktop site enabled if mobile controls are limited).
3. Upload the files and folders from this ZIP. Keep `index.html` at the repository root.
4. Commit the upload to the `main` branch.
5. In repository **Settings → Pages**, select **Deploy from a branch**, branch `main`, folder `/ (root)`, then Save.
6. Wait for GitHub Pages to publish. Your site URL will be `https://ajby26952-bit.github.io/neet-quest/`.
7. Open that URL in Chrome on Android → menu ⋮ → **Add to Home screen** or **Install app**.
